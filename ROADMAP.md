# Roadmap

Things I plan to work on as I continue developing Marketplace.

## Communication
- Add in-app chat between buyers and sellers.
- Allow users to share product details during conversations.
- Add notifications for new messages.

## Orders and Delivery
- Notify buyers when a seller's product has been picked up.
- Add delivery status updates so buyers can follow their orders.
- Allow buyers to confirm when an order has been delivered.
- Improve how order status changes are handled.

## Payments
- Improve payment status tracking.
- Handle failed and pending transactions better.
- Add a proper order and payment history for users.

## Seller Features
- Allow sellers to edit and manage their product listings.
- Add better tools for tracking incoming orders.
- Improve product availability and stock management.

## User Experience
- Improve the mobile experience.
- Make product discovery and filtering easier.
- Improve the overall checkout process.
